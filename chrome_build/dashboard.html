Intervention Options
Enable Mindful Pause (Breathing/Type Text) Require a mindful breathing pause or text typing before opening target sites If enabled, opening a blocked website forces a mindful pause/breathing task first. If disabled, you bypass the pause screen and go directly to the website (where the original Anchor Sinking scroll/reel blocker remains active).
Intentional website switching Choose bypass behavior mode • Allow opening once: Checks back in on the target site every single time you navigate to it or open it in a new tab.
• Bypass Cooldown: Grants you an unrestricted browsing window for a set time (e.g., 5 minutes) across all tabs, after which the check-in triggers again.
Bypass Cooldown Duration (Minutes) Free browsing time before requiring another pause Sets the timer for the Bypass Cooldown session. After unlocking a site, you can browse it freely for this duration without being interrupted by further check-ins.
Close tab on intervention exit Close tab immediately if you cancel the opening If enabled, choosing "No, close this tab" on the check-in screen will immediately close the current browser tab. If disabled, the browser will attempt to navigate you back to your previous page or Google.
Anchor Sinking & Reel Blocker Settings
Show Depth Indicator Display the visual depth meter and red marker on the right side of the screen when sinking
Virtual Sinking Depth (Meters) Maximum depth in meters you can sink before scrolling is locked Determines the physical scroll limit on target websites. Once you scroll past this depth, downward scrolling is blocked and a rock floor is drawn. Default is 10m.
Scroll Buffer Depth (Meters) Depth in meters you can scroll before the color fade overlay begins Allows you to scroll freely for a small distance before the blue oceanic sinking overlay begins to darken. Default is 2m.
Reels Watch Limit Maximum number of Shorts/Reels/TikToks you can view before scrolling is locked For short video sites (YouTube Shorts, TikTok, Instagram Reels), this sets the maximum number of videos you are allowed to swipe through before scrolling is blocked. Default is 10.
Reels Buffer Limit Number of short videos you can watch before the color overlay begins to darken Gives you a buffer of short videos to view freely before the blue oceanic overlay begins to fade in. Default is 2.
Animation Density (CPU Level) Adjust count of background sea creatures for browser performance Controls the number of swimming fish and jellyfish rendered in the background of the depth blocker. Set to Low or None if you experience scroll lag.

Block

Completely block distracting websites, and reclaim your routine using a schedule.

Block Setup

• Blocklist Mode: The blocker intercepts all pages on the web except the exclusions listed below.
• Allowlist Mode: The blocker is completely inactive by default, only intercepting the target websites listed below.
Enter one domain per line (e.g., instagram.com, youtube.com). Subdomains like m.instagram.com are automatically handled.

Focus Schedules

Enable Schedule
Only run blocking during focus hours. Outside of the configured hours, the blocker will automatically turn off.
Strict Mode Lock
Locks the dashboard during scheduled hours. You will be unable to disable the schedule, modify target websites, or change bypass options until the session ends.
