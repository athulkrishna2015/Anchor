Welcome to Anchor ⚓

Before you dive in, how would you like Anchor to operate?

Blocklist Mode (Run Everywhere)

Anchor will run on every website by default. You can manually disable it on sites where you don't want it (e.g. work sites).

Allowlist Mode (Run Only Where Specified)

Anchor is completely disabled everywhere by default. You manually enable it only on the specific sites you struggle with (e.g. YouTube, TikTok).
